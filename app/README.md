# app/ : บ้านของแอปมือถือ (สงวนที่ไว้)

สถานะ: ยังไม่มีโค้ด (31 ต.ค. 2026) โฟลเดอร์นี้ถูกจัดไว้ล่วงหน้าตามคำสั่ง Master ในการรื้อโครงราก F7 ให้ "เว็บคือเว็บ แอปคือแอป" ก่อนเริ่มทำแอปจริง

## อนาคตของโฟลเดอร์นี้ (ตามขั้น S7 ของแผนหลัก)

- แอป APK ด้วย React Native เขียนหน้าจอใหม่ทั้งหมด ไม่ต้องหน้าตาเหมือนเว็บเป๊ะ แต่ฟังก์ชันตรงกับเว็บ (การตัดสินของ Master 15 ต.ค. 2026)
- ใช้หลังบ้านชุดเดียวกับเว็บ: backend/api, backend/db, backend/edge ผ่าน HTTP เหมือนเดิม
- ตรรกะที่ใช้ร่วมกับเว็บอยู่ที่ ../core (TypeScript) นำเข้าได้เลย ห้ามคัดลอกสำเนามาไว้ที่นี่

## กติกาของบ้านนี้

1. ห้ามเอาของฝั่งเว็บมาวาง (ของเว็บอยู่ที่ ../web ทั้งหมด รวมหน้าจอ สไตล์ และเครื่องยนต์เดิม)
2. ตรรกะที่เว็บต้องใช้ด้วย ต้องอยู่ที่ ../core เท่านั้น แล้วทั้งเว็บและแอปนำเข้าจากที่เดียวกัน
3. ส่วนต่อที่ต่างกันตามแพลตฟอร์ม (ที่เก็บข้อมูลในเครื่อง การเดินหน้า การแจ้งเตือน) ทำเป็น adapter ที่ฝั่งละชุด ยังไม่สร้างจนกว่า Master รับรองแบบ (ดู ../docs/plan/steps/S7-structure-share-design.md ข้อ 6)
