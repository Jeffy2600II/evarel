ORDIVEL — LOGO FAMILY v11 · PREMIUM FINISH · 4 แบบให้เลือก
================================================================

กติกาที่ตกลงกัน: สัญลักษณ์ = สัญลักษณ์ ชื่อ = ชื่อ
ทุกล็อกอัพสะกดคำว่า Ordivel ครบทุกตัวอักษร — สัญลักษณ์ไม่ถูกใช้แทนตัว O
(ป้องกันการเข้าใจผิดว่าชื่อถูกตัดตัวอักษร)

กติกา v8.2 — โครงสัญลักษณ์หลักเป๊ะเดียวกัน 100% ทุกไฟล์ · ลายข้างในเฉพาะเวอร์ชันตามต้นฉบับ:
  โครงหลัก (โค้งหนา โค้งเล็ก ช่องเว้น ลูกปัด — ตำแหน่ง/ความยาว/มุมทุกเส้น) มาจาก
  เวกเตอร์ชุดเดียวกัน (path ระดับ byte-identical) — ห้ามคลาดเคลื่อน
  ตรวจอัตโนมัติแล้ว: 1 core signature ต่อ 1 แบบ (ครบ 20 ไฟล์สัญลักษณ์)
  + ตรวจซ้ำรอบนี้: โครงหลัก v11 เทียบ v10 เหมือนกัน 100% ไม่มีเส้นเดียวขยับ
  ส่วนลายข้างใน (แฮร์ไลน์แกะสลัก / สเวปแสงแก้ว / ประกายสเปกุลาร์ / หางดาว /
  คีย์ไลน์ / แสงบน / จุดหมุด / ฮาโล) เป็นดีไซน์เฉพาะของแต่ละเวอร์ชันตามต้นฉบับ —
  เวอร์ชันไหนไม่เคยมี ไม่ใส่ (เช่น mark-white, mark-micro(-white),
  appicon/circle-violet และ mask-icon เรียบสะอาดตามแบบเดิม)
  ดูชีต "CANONICAL SYMBOL" ในหน้าของแต่ละแบบ (ระบุลายของแต่ละไฟล์ใต้ภาพ)

ใหม่ใน v11 · PREMIUM FINISH (อัปเกรดวัสดุ-ผิว-ขอบ — โครงสร้างไม่ขยับ):
  - ไล่เฉดออโรรา 6 สต็อป — ช่วงค่าความสว่างกว้างขึ้น บนสว่าง ล่างลึก ผิวแก้วมีมิติ
  - ดาร์กโหมดกระจ่างขึ้นทั้งชุด — สัญลักษณ์เด้งออกจากพื้นเข้ม ไม่จม
  - พื้นไอคอน 3 ชั้น: spotlight มุมบนซ้าย + vignette มุมล่างขวา + เส้นขอบ
    keyline ละเอียดเท่าผม (ครบทั้งสี่เหลี่ยม / วงกลม / favicon)
  - ลูกปัดไข่มุกทรงกลมจริง — เพิ่มร่มม่วงที่ขอบล่าง ไม่ดูเป็นสติกเกอร์แปะ
  - ล็อกอัพชิดขึ้น: 0.22× → 0.16× ของความสูงสัญลักษณ์ (แบบซ้อน 0.20×)
    และตัวชื่อ Ordivel หนาขึ้นหนึ่งระดับ (Space Grotesk 550 → 600)
  - วงเมริเดียน: แรมป์สี 24 ชั่วโมง ละเอียดขึ้นเป็น 10 สต็อป ไหลลื่นขึ้น
  - PNG ขนาดใหญ่ (512/1024) เรนเดอร์ supersample 2× แล้วย่อ ตัดแถบสี
    (banding) · favicon ยังเรนเดอร์ตรงทุกขนาดตามสัญญาเดิม
  - สมดุลรายละเอียด v8.2 ยังอยู่ครบ: ลายข้างในเฉพาะเวอร์ชันตามต้นฉบับ —
    สัญลักษณ์ขาว (mark-white / appicon / circle-violet / mark-micro(-white))
    เรียบสะอาด · favicon คงแฮร์ไลน์+ประกายไข่มุกตามที่อนุมัติไว้
    (apple-touch-icon-180 / icon-192 / icon-512 สร้างใหม่จากไฟล์ล่าสุด)

แต่ละโฟลเดอร์ (1-ordinal / 2-meridian / 3-facet / 4-cadence) มีไฟล์ครบเหมือนกันหมด:
  favicon.ico          วางที่รากเว็บ — แบบที่ 1: 6 ขนาดในไฟล์เดียว (16/32/48/64/128/256)
                       ทุกเฟรมเรนเดอร์ตรงจากเวกเตอร์ที่ขนาดจริง (ไม่ใช่ภาพย่อ)
  site.webmanifest     (แบบที่ 1) PWA manifest พร้อมไอคอน 192/512 + theme color
  svg/                 เวกเตอร์ทุกไฟล์ (ต้นฉบับ ขยายได้ไม่จำกัด)
    favicon.svg        (แบบที่ 1) favicon เวกเตอร์ — เบราว์เซอร์ทันสมัยใช้ได้เลย
    mask-icon.svg      (แบบที่ 1) Safari pinned-tab template (สีเดียว)
    mark-gradient      สัญลักษณ์ไล่เฉดพรีเมียม (พื้นโปร่งใส)
    mark-violet        เวอร์ชันสีม่วงแบน (งานพิมพ์)
    mark-ink / mark-white   โมโนโครม
    mark-micro(-white) ชื่อไฟล์เดิม — โครงหลักเดียวกันเป๊ะกับ mark หลัก
                       (ยกเลิกรูปแบบย่อวาดใหม่แล้ว) และเรียบสะอาด ไม่มีลายข้างใน ตามต้นฉบับ
    appicon-violet/night/paper   ไอคอนแอปสี่เหลี่ยมมุมมน 1024 box
    circle-violet/night/paper    ไอคอนแอปวงกลม ไฟล์ครบเท่ากันทุกอัน
    lockup-ink / lockup-white            ล็อกอัพแนบแน่น (สัญลักษณ์ + Ordivel เต็ม)
    lockup-stacked-ink / -white          ล็อกอัพซ้อน
    wordmark-ink / wordmark-white        ตัวชื่อเดี่ยว
    construction     แผ่นโครงสร้าง: มุมทอง 137.5°, 25°, 162.5°
    detail-zoom      ภาพซูมรายละเอียดพรีเมียมของสัญลักษณ์
  png/                 PNG ขนาดใช้งานจริง (1024/512/256/128/64/48/32/16)

ชุด favicon ของแบบที่ 1 (ตัวที่เลือก) ครบสมบูรณ์พิเศษ:
  favicon-16/32/48/64/128/256.png + apple-touch-icon-180.png + icon-192/512.png
  ทุกไฟล์คือดีไซน์เดียวกัน (ชิปม่วงไล่เฉด + สัญลักษณ์ขาว) เรนเดอร์ตรงจากเวกเตอร์
  พร้อมปรับสัดส่วนเฉพาะขนาด — โค้งหนา โค้งเล็ก ช่องเว้น ลูกปัด ครบทุกชิ้นแม้ 16px

สัญลักษณ์ทั้งหมดเดินบน DNA เดียวกัน:
  ตัว O = วงวันของคุณ · จุด "รายการถัดไป" ที่ 25° · ช่องเปล่าที่ 162.5°
  สองตำแหน่งห่างกัน 137.5° พอดี (มุมทอง)

เลือกแบบที่ชอบ แล้วใช้โฟลเดอร์นั้นเป็นชุดต้นฉบับได้เลย
