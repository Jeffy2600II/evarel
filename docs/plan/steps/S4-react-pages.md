# S4 แปลงเป็น React ทีละหน้า (ช่วง: ไกล เป้าหมายกับเกณฑ์เท่านั้น)

กลับไปที่ [แผนหลัก](../MASTER-PLAN.md) | ขั้นก่อนหน้า [S3](S3-nextjs-wrap.md) | ขั้นถัดไป [S5](S5-release.md)

## เป้าหมาย
แปลงหน้าของแอปเป็น React ทีละแท็บ โดยพฤติกรรมและหน้าตาไม่เปลี่ยน

## ผลลัพธ์ที่ตรวจได้
1. แต่ละหน้าที่แปลงผ่านประตู 3 ชุด (ภาพ 0 พิกเซล ชุดทดสอบ route และฟีเจอร์ ออฟไลน์) ก่อนเริ่มหน้าถัดไป
2. หน้าที่ยังไม่แปลงยังทำงานได้ตามเดิมตลอดช่วงแปลง
3. ไม่ผ่านประตูใด ต้องย้อนกลับหน้านั้น

## สถานะ
ยังไม่เริ่ม ยังไม่มีไฟล์ React ในที่เก็บ

## สถานะการเลื่อน
ขั้นนี้เป็นขั้นที่เลื่อนได้ถ้าเวลาไม่พอ เพราะ S3 ทำให้แอปทำงานได้เหมือนเดิมอยู่แล้ว การตัดสินว่าเลื่อนหรือไม่เป็นของ Master เท่านั้น

## สิ่งที่ยังไม่ทราบ
- เวลาที่ใช้จริงต่อหน้า ยังไม่เคยวัด
- ลำดับหน้าที่ควรแปลงก่อน

## รายละเอียดเมื่อใกล้ถึง
ขยายเป็นงานย่อยเมื่อ S3 ผ่าน แผนเดิมอยู่ใน docs/backend-plan/02-ts-nextjs-conversion.md หัวข้อ Stage 3 ใช้เป็นข้อมูลอ้างอิงเท่านั้น
