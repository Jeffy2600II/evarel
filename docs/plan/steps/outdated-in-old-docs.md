## ข้อที่รายงานสำรวจอ้างแล้วตรวจไม่ผ่าน (ห้ามนำไปใช้)

- รายงานสำรวจเขียนว่ามี scheduled handler ใน src/index.ts แต่ค้นแล้วไม่พบ จึงถือว่าไม่มี
- รายงานสำรวจเขียนว่าโมดูลส่งเมลใช้ Nodemailer แต่โมดูลเขียนเอง คุยโปรโตคอล SMTP ตรงผ่าน connect()
