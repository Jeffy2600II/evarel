# S3 ครอบด้วย Next.js (ช่วง: กลาง รายละเอียดบางส่วน)

กลับไปที่ [แผนหลัก](../MASTER-PLAN.md) | ขั้นก่อนหน้า [S2](S2-notify-ai.md) | ขั้นถัดไป [S4](S4-react-pages.md)

## เป้าหมาย
แอปเดิมทำงานเหมือนเดิมทุกอย่างเมื่ออยู่บน Next.js แบบ static export โดยยังใช้แม่แบบหน้าเดิม ยังไม่แปลงเป็น React

## ผลลัพธ์ที่ตรวจได้
1. ภาพหน้าจอเหมือนต้นฉบับ 0 พิกเซล
2. ชุดทดสอบ route 22 ข้อ และชุดทดสอบฟีเจอร์ 13 ข้อ ผ่านครบ
3. ใช้งานออฟไลน์ได้ รวมปฏิทินที่เก็บไฟล์เองไว้ในเครื่อง
4. service worker ทำงานและแคชครบ ไม่ทำให้ผู้ใช้เห็นหน้าเก่าค้าง

## ข้อเท็จจริงที่ตรวจแล้ว
- ES module ของ 25 ไฟล์ (27 สคริปต์ชนิดโมดูล) ผ่านประตู 5 ชุดและ deploy แล้ว (app-esm2, SW v44) นี่คือฐานของขั้นนี้
- ยังไม่มีไฟล์ Next.js หรือ React ในที่เก็บเลย (ตรวจ 13 ต.ค. 2026)
- หน้าเปล่าของ Next.js static export วัดจริงแล้ว First Load JS ประมาณ 102 kB ต้องวัดซ้ำกับแอปจริง

## สิ่งที่ยังไม่ทราบ
- เวลาที่ใช้จริง ยังไม่ได้ประเมินจากการวัด
- แคชของ service worker ชดเชยขนาดที่เพิ่มได้หรือไม่
- จำนวนไฟล์ที่ได้หลัง build เทียบเพดาน Static Assets 20,000 ไฟล์ (คาดว่าห่างมาก ยังไม่ได้นับ)

## รายละเอียดเมื่อใกล้ถึง
ขยายเป็นงานย่อยและเกณฑ์รายขั้นเมื่อ S1 และ S2 ใกล้จบ แผนเดิมของขั้นนี้อยู่ใน docs/backend-plan/02-ts-nextjs-conversion.md หัวข้อ Stage 2 ใช้เป็นข้อมูลอ้างอิง แต่ต้องตรวจซ้ำกับสถานะจริงก่อนลงมือ
