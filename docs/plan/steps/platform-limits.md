# ข้อจำกัดแพลตฟอร์มที่แผนต้องเคารพ

ที่มา: เอกสารทางการ อ่านเมื่อ 13 ต.ค. 2026 ผลสำรวจเต็มอยู่ที่ .state/work/plan-restructure-r43/facts-B-platform-live.md ของเอเจนต์
รายการที่ไม่พบในเอกสารทางการระบุว่า ยังไม่ทราบ ห้ามใช้ความจำแทน ตรวจซ้ำก่อนอ้างอิงถ้าเกินหนึ่งเดือน

สถานะการตรวจ: ส่วน Cloudflare Workers และ Static Assets ผู้เขียนแผนเปิดอ่านหน้าเอกสารทางการเอง 13 ต.ค. 2026 (หน้าระบุปรับปรุงล่าสุด 12 ต.ค. 2026) ตรงกับตารางนี้ทุกค่า ส่วน Supabase และ Groq ได้ค่ามาจากผลสำรวจของเอเจนต์ช่วยที่อ่านเอกสารทางการ ผู้เขียนแผนยังไม่ได้เปิดอ่านซ้ำเอง

## Cloudflare Workers (แผนฟรี)

| ข้อจำกัด | ค่า | เอกสาร |
|---|---|---|
| เวลา CPU ต่อคำขอ และต่อ Cron Trigger | 10 มิลลิวินาที เวลารอเครือข่ายและรอฐานข้อมูลไม่นับเป็นเวลา CPU | developers.cloudflare.com/workers/platform/limits/ |
| Subrequest ต่อคำขอ | 50 | เหมือนด้านบน |
| คำขอต่อวัน | 100,000 (รีเซ็ต 00:00 UTC) | เหมือนด้านบน |
| Cron Triggers ต่อบัญชี | 5 | เหมือนด้านบน |
| ขนาดสคริปต์ | 64 MiB | เหมือนด้านบน |
| จำนวน Worker ต่อบัญชี | 100 | เหมือนด้านบน |
| เชื่อมต่อ TCP ด้วย connect() | ห้ามพอร์ต 25 | developers.cloudflare.com/workers/runtime-apis/tcp-sockets/ |

## ผลต่อแผน

- การแจ้งเตือนตามเวลาที่ผู้ใช้ตั้ง ต้องใช้ตัวจัดเวลาที่ทำงานภายใน 10 มิลลิวินาทีต่อครั้ง และไม่เกิน 5 Cron Triggers ต่อบัญชี ทุกโปรเจกต์ในบัญชีใช้โควตา 5 ตัวนี้ร่วมกัน
- การส่งอีเมลเองผ่าน Gmail ใช้พอร์ต 465 ซึ่งไม่ถูกห้าม (พิสูจน์ด้วยการส่งจริงเมื่อ 12 ต.ค. 2026)
- อีเมลในตัวของ Supabase ใช้เปิดสาธารณะไม่ได้ จึงต้องส่งเอง

## ที่ยังไม่ได้ตรวจ

- โควตาและเงื่อนไขของ OpenRouter สำรอง
- ข้อจำกัดอื่นของ TCP sockets นอกจากพอร์ต 25 (เอกสารไม่ระบุ)
- ราคาหรือนโยบายที่เปลี่ยนหลังวันที่อ่าน
