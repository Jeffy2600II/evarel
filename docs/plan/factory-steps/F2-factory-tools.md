# F2 เครื่องมือโรงงาน (เอกสาร B3, B5, B7)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F1](F1-warehouse-and-molds.md) | ถัดไป [F3](F3-trays.md)

## เป้าหมาย
สร้างทุกอย่างในโซน `tools/` ตามเอกสาร เอกสาร B8 ระบุว่านี่คืองานชิ้นแรกของโครงใหม่ "เครื่องยังไม่มี โรงงานยังไม่หมุนเร็ว" หลักคัดกลไกของเอกสาร: เก็บเฉพาะตัวที่เครื่องทำให้เอง ตัวไหนต้องให้คนนั่งทำ ตัดทิ้ง

## เครื่องมือที่ต้องมี (ครบตามเอกสาร)
| เครื่องมือ | หน้าที่ ตามเอกสาร |
|---|---|
| เบ้าจูน | สั่งครั้งเดียวได้โฟลเดอร์พร้อมโครงครบสามชั้น ไม่เริ่มจากกระดาษเปล่า เขียนบัตรประจำกล่องให้เอง |
| เครื่องตรวจ | ตรวจกติกา: กล่องล้น ไฟล์เกินขนาด ชื่อผิดแบบ ไม่ผ่านแล้วบอกว่าผิดข้อไหนเพราะอะไร |
| ตัววาดแผนที่ | สแกนโครงสร้างจริงแล้ววาดใหม่ทุกครั้งที่โค้ดเปลี่ยน กดลิงก์เข้าไฟล์จริงได้ |
| ทะเบียนใครใช้ใคร | ก่อนแก้ชิ้นไหน รู้ว่ากระเทือนหน้าไหนบ้าง |
| X-ray รายหน้า | สั่งตรวจหน้าเดียวได้ทันที ไม่สแกนทั้งโรงงาน |
| ห้องโชว์แม่พิมพ์ | (สร้างใน F1.5) |
| บัตรประจำกล่อง | สองส่วน: ส่วนสั้นสำหรับคนอ่าน ส่วนกฎที่เครื่องอ่านได้สำหรับ agent และเครื่องตรวจ เขียนที่เดียว (เอกสารข้อ C) |
| แผ่นตรวจรับประจำกล่อง | ผ่านตรวจ + บัตรครบ + ลงทะเบียน ครบสามข้อถึงเรียกว่าเสร็จ ไม่มีเสร็จแบบเกือบ |
| โซนกักรอตรวจ | กล่องใหม่ที่ยังไม่ผ่านตรวจอยู่โซนกัก ไม่ปนกับของที่ส่งแล้ว |
| แก้ย้อนรายกล่อง | พังตรงไหนย้อนกล่องนั้นกล่องเดียว |
| ตารางถาม-ตอบกลาง | แก้ในหน้า → กล่องนั้น / แก้ปุ่มทั้งเว็บ → แม่พิมพ์ / เพิ่มหน้า → เบ้าจูน / ข้อมูล → ถาด |
| ไฟล์ "กฎของบ้านนี้" | ไฟล์เดียว เฉพาะที่ต่างจากมาตรฐานพร้อมเหตุผล อ่านจบหนึ่งหน้า |
| กล่องตัวอย่าง | หนึ่งกล่องที่ทำถูกทุกกฎ เปิดดูหนึ่งนาทีก็ลอกรูปแบบได้ |
| สนามซ้อม | เสียบข้อมูลปลอมดูผลก่อน ไม่ต้องรอต่อของจริง (B3 ข้อ 4) |

## กฎแกนที่เครื่องตรวจบังคับ
เอกสารข้อ C: "ตัวตรวจบังคับ 5-6 ข้อพอ ที่เหลือเป็นคำแนะนำ เพราะกฎ 20 ข้อทำให้ท้อ" ใช้กติกาข้อ 6 ของแผนภาพรวม (B6) เป็นฐาน ให้ Master เลือก 5-6 ข้อที่บังคับ (Q2)

## ผลลัพธ์ที่ตรวจได้
1. สั่งเบ้าจูนด้วยชื่อกล่องหนึ่งชื่อ ได้กล่องสามชั้นที่เครื่องตรวจผ่านทันทีโดยไม่แก้มือ (ทดสอบ 3 ชื่อ)
2. ฉีดกติกาผิดตัวอย่างต่อกฎ แล้วเครื่องตรวจตกพร้อมบอกข้อและเหตุผล
3. ตัววาดแผนที่รันสองครั้งบนโค้ดเดียวกันได้ผลเหมือนกันทุกไบต์ ลิงก์ทุกลิงก์ชี้ไฟล์จริง
4. ทะเบียนใครใช้ใครตอบได้ว่าแก้ชิ้นหนึ่งกระทบหน้าไหนบ้าง
5. เครื่องมือเดิมใน `tools/` (dep_manifest, dep_symbols, typecheck) ถูกใช้ต่อ ไม่เขียนตัววิเคราะห์ซ้อน

## ความเสี่ยง
| ความเสี่ยง | วิธีลด |
|---|---|
| กลไกเพิ่มแล้วกลายเป็นของต้องดูแล (เอกสารเตือนเอง) | ทุกกลไกมีเจ้าของคือสคริปต์ ไม่ใช่คน |
| เครื่องตรวจเงียบตรวจไม่เจอจริง | ทดสอบฉีดผิดทุกกฎ |
| เบ้าจูนเขียนทับกล่องที่มีอยู่ | เบ้าจูนสร้างใหม่อย่างเดียว ปฏิเสธชื่อว่าง ชื่อซ้ำ ชื่อมีเลขเวอร์ชัน |
