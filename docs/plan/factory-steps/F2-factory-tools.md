# F2 เครื่องมือโรงงาน (ช่วง: ใกล้ รายละเอียดเต็ม)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F1](F1-close-window-leaks.md) | ถัดไป [F3](F3-tokens-contracts.md)

## เป้าหมาย
สร้างเครื่องมือสามตัวใน `tools/` ตามเอกสารโรงงาน B8 ที่ว่า "เครื่องยังไม่มี โรงงานยังไม่หมุนเร็ว นี่คืองานชิ้นแรกของโครงใหม่":
1. เบ้าจูน (generator) สั่งครั้งเดียวได้กล่องครบสามชั้น
2. ตัวตรวจ (checker) กฎแกน 5-6 ข้อ บอกว่าผิดข้อไหนเพราะอะไร
3. ตัววาดแผนที่ (mapper) วาดจากโค้ดจริงเท่านั้น ไม่เขียนมือ
หลักคัดกลไก (จากเอกสารโรงงาน): เก็บเฉพาะตัวที่ เครื่องทำให้เอง ตัวไหนต้องให้คนนั่งทำ ตัดทิ้ง

## ผลลัพธ์ที่ตรวจได้
1. สั่งเบ้าจูนด้วยชื่อกล่อง 1 ชื่อ ได้โฟลเดอร์ที่ตัวตรวจผ่านทันทีโดยไม่แก้มือ (วัดซ้ำ 3 ชื่อต่างกัน)
2. ตัวตรวจตกเมื่อฉีดกติกาผิดตัวอย่างอย่างน้อย 1 ข้อต่อกฎ (เกณฑ์ระบบข้อ 5) และข้อความที่ตกบอกชื่อกฎกับเหตุผล
3. ตัววาดแผนที่รันสองครั้งบนโค้ดเดียวกันได้ผลเหมือนกันทุกไบต์ (ทำซ้ำได้) และลิงก์ในแผนที่ชี้ไฟล์ที่มีอยู่จริงทุกลิงก์
4. ตัวตรวจอยู่ในโหมด "เตือน" ไม่ใช่ "บล็อก" (ตาม D3) จนกว่า F4 พิสูจน์
5. เครื่องมือเดิมใน `tools/` ไม่ถูกทำซ้ำ: ตัวตรวจเรียก/ห่อ `dep_manifest`, `dep_symbols`, `typecheck` ที่มีอยู่ (ไม่เขียนตัววิเคราะห์ซ้อน)

## กฎแกนที่เสนอ (5-6 ข้อ ตาม "กฎแกนน้อยแต่บังคับจริง") ให้ Master ปรับได้
| # | กฎ | ตรวจด้วย |
|---|---|---|
| R1 | กล่องหนึ่งมีสามชั้นครบ: โครงหน้า, parts, tray | โครงสร้างโฟลเดอร์ |
| R2 | กล่องไม่อ้างกล่องอื่นตรงๆ ใช้ผ่านชิ้นส่วนกลางหรือถาดเท่านั้น | กราฟ import |
| R3 | ไม่มี `window.` รับของข้ามกล่อง | ตัววัด window ที่ F1 สร้าง |
| R4 | ไม่มีค่าสี/ระยะฝังตรงนอกแม่พิมพ์กลาง | สแกน CSS/JSX (ใช้ได้จริงหลัง F3) |
| R5 | ชื่อไฟล์/โฟลเดอร์ไม่มีเลขเวอร์ชัน | แพตเทิร์นชื่อ |
| R6 | ทุกกล่องลงทะเบียนในสารบัญและมีบัตรประจำกล่อง | เทียบสารบัญกับโฟลเดอร์ |
กฎที่เป็นคำแนะนำ ไม่บังคับ: ขนาดไฟล์/กล่อง (เกณฑ์ตัวเลขต้องได้จาก F4 ไม่เดา)

## เช็กลิสต์ตอบจุดเสี่ยง
- ค่าว่าง/ขอบเขต: เบ้าจูนต้องปฏิเสธชื่อว่าง ชื่อซ้ำ ชื่อมีเลขเวอร์ชัน ชื่อไทย/อักขระพิเศษที่ทำให้พาธพัง
- ผลข้างเคียง: เบ้าจูนห้ามแก้ไฟล์เดิม สร้างใหม่อย่างเดียว และต้องไม่เขียนทับกล่องที่มีอยู่
- ทรัพยากร: ตัวตรวจต้องรันรายกล่องได้ ไม่สแกนทั้งโรงงานทุกครั้ง
- ย้อนกลับ: เครื่องมือใหม่อยู่ในไฟล์ใหม่ ลบทิ้งได้ ไม่แก้ของเดิม

## ความเสี่ยง
| ความเสี่ยง | ผลกระทบ | วิธีลด |
|---|---|---|
| กลไกเพิ่มแล้วกลายเป็นของต้องดูแล (ความเสี่ยงที่เอกสารโรงงานเตือนเอง) | ภาระเพิ่ม | ใส่เฉพาะที่เครื่องทำให้เอง; ทุกกลไกมีเจ้าของคือสคริปต์ ไม่ใช่คน |
| ตัวตรวจบังคับเร็วไป ขวางงานจริง | ท้อ | เริ่มเป็นเตือน (D3) |
| ตัวตรวจ "เงียบ" ตรวจไม่เจอจริง | ผ่านหลอก | ทดสอบฉีดผิดทุกกฎ (เกณฑ์ข้อ 2) พิสูจน์หูไม่หนวก |
