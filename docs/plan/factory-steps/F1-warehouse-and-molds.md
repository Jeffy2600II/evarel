# F1 สร้างโครงโกดังและแม่พิมพ์กลาง (เอกสาร B1)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F0](F0-contract-baseline.md) | ถัดไป [F2](F2-factory-tools.md)

## เป้าหมาย
สร้างโครงตามเอกสารตรงตัว: `app/pages/ shared/ styles/ data/ tools/` และทำให้ `styles/` เป็นแม่พิมพ์กลางจุดเดียว: สี ฟอนต์ ระยะห่าง ขนาด ปุ่มมาตรฐาน มาจากตารางเดียว ตามคำของเอกสาร "เปลี่ยนฟอนต์ทั้งเว็บ = แก้บรรทัดเดียว"
ขั้นนี้ยังไม่ย้ายหน้า เป็นการสร้างโกดังเปล่าและตารางแม่พิมพ์ที่ค่าตรงกับของเดิมทุกค่า

## ผลลัพธ์ที่ตรวจได้
1. โฟลเดอร์ `pages/ shared/ styles/ data/ tools/` มีอยู่ใต้ `app/` ตรงชื่อเอกสาร
2. `styles/` มีตารางแม่พิมพ์ตารางเดียว ครอบคลุมทุกค่าที่ใช้อยู่จริง: สี ระยะ มุม เงา ขนาดและฟอนต์ตัวอักษร ค่าแต่ละตัวตรงค่าเดิมตัวต่อตัว ไม่ปัด ไม่รวม
3. เปลี่ยนค่าฟอนต์ในตารางบรรทัดเดียว ฟอนต์ทั้งเว็บเปลี่ยนตาม (พิสูจน์แล้วเปลี่ยนกลับ)
4. ค่าสีและระยะที่ฝังตรงนอกแม่พิมพ์ลดลงจากเส้นฐาน (app.css สี 152 / px 1,033 ; design.css สี 128 / px 957) จนเหลือ 0 หรือเหลือเฉพาะที่ระบุเหตุผล
5. ภาพ 0 พิกเซลทุกฉากเทียบภาพอ้างอิง F0 (หลักฐานว่าตั้งชื่อค่าเดิมจริง)
6. ฟอนต์ยังเป็นฟอนต์ระบบตามที่ Master ชอบ ไม่เพิ่มฟอนต์ที่โหลดเอง

## งานย่อย

|---|---|
| F1.1 | สร้างโซนเปล่าห้าโซนพร้อมไฟล์อธิบายโซนละหนึ่งหน้า |
| F1.2 | ทำบัญชีค่าที่ใช้จริงด้วยสคริปต์วัดจาก CSS ไม่คัดจากตัวเลขเก่า |

## หมายเหตุ
`tailwind.config.cjs` ปัจจุบันชี้สีไปที่ตัวแปร `--c-*` 25 ตัว และมีคอมเมนต์ห้ามแก้ค่าเอง แม่พิมพ์ใหม่ใช้ชุดตัวแปรเดียวกันนี้เป็นฐาน ไม่สร้างชุดที่สอง

## ความเสี่ยง
| ความเสี่ยง | วิธีลด |
|---|---|
| ตั้งชื่อค่าแล้วภาพขยับ 1 พิกเซล | ค่าเดิมตรงตัว ตรวจภาพรายไฟล์ ย้อนรายไฟล์ |
| ประตูภาพมองไม่เห็นสถานะที่ไม่ได้ถ่าย | ระบุฉากที่ไม่ครอบคลุม ตรวจเพิ่มด้วย computed style |
