# F5 สายพานอัตโนมัติ (เอกสาร B5)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F4](F4-pilot-boxes.md) | ถัดไป [F6](F6-migrate-rest.md)

## เป้าหมาย
ต่อเครื่องมือ F2 เข้า GitHub Actions ตามเอกสาร B5 ทั้งสี่ข้อ:
1. วาดแผนที่ทุกครั้งที่ push สแกนโครงสร้างจริงแล้ววาดใหม่ ไม่มีวันล้าสมัย
2. ตรวจกติกา ไม่ผ่าน = ไม่ปล่อย กฎเป็นเครื่องตรวจ ไม่ใช่ความจำ
3. ทะเบียนใครใช้ใคร
4. X-ray ตรวจรายหน้า

ต่อยอด `.github/workflows/web.yml` ที่มีอยู่ (ตรวจโน้ตรุ่น ตรวจไฟล์คอมไพล์ตรงซอร์ส build ตรวจ release) เพิ่ม job เข้าไฟล์เดิม ไม่สร้าง workflow ซ้อน

## ผลลัพธ์ที่ตรวจได้
1. ทุก push วาดแผนที่ใหม่เองและเผยแพร่เป็นไฟล์เปิดอ่านได้ ลิงก์ชี้ไฟล์จริง
2. push ตัวอย่างที่ฝ่าฝืนกฎแกนหนึ่งข้อถูกตีกลับพร้อมบอกข้อและเหตุผล
3. เวลารันของ job ใหม่วัดจริงแล้ว อยู่ในโควตาฟรีของ GitHub Actions
4. ถอด job ออกแล้วเครื่องตรวจยังรันมือได้ด้วยคำสั่งเดียว

## ความเสี่ยง
| ความเสี่ยง | วิธีลด |
|---|---|
| แผนที่ commit กลับแล้วชน hook หรือวน CI | เผยแพร่เป็น artifact หรือหน้าแยก |
| workflow ติดตั้ง web-shell แยก ทำให้ job ใหม่ช้า | ใช้แคชเดิมของ job `check` |

## ผลที่ทำจริง (Oct 28, 2026)
job `factory` ถูกเพิ่มเข้า `web.yml` เดิม และ `deploy-forge` ต้องรอ (`needs: [check, factory]`)

| ผลลัพธ์ที่ตรวจได้ | หลักฐาน |
|---|---|
| 1. ทุก push วาดแผนที่ใหม่และเผยแพร่ | artifact `factory-out` (แผนที่ + X-ray) ของ run บน develop ผ่าน และขั้น "แผนที่ที่ commit ต้องไม่ล้าสมัย" บังคับให้ `docs/FACTORY-MAP.md` ตรงของจริง (ไม่ commit กลับ ใช้ `contents: read`) |
| 2. push ที่ฝ่าฝืนถูกตีกลับพร้อมเหตุผล | PR ทดลองฝ่าฝืน BOX-05: `factory` ตกที่ขั้นตรวจกติกา ล็อกบอก `[BOX-05] parts/StatsChart.jsx ... เข้าถึง window โดยตรงนอกถาดข้อมูล` `deploy-forge` ถูกข้าม ปิด PR และลบสาขาทดลองแล้ว |
| 3. เวลาอยู่ในโควตาฟรี | `factory` 14 วินาทีบน GitHub (เครื่องมือในเครื่องรวม 0.9 วินาที) ไม่ต้อง `npm ci` |
| 4. ถอด job แล้วรันมือได้ | `node app/tools/checker.mjs --all` |

ข้อสังเกต: `mapper.mjs` ไม่มี `--help` อาร์กิวเมนต์แรกถูกใช้เป็นพาธเอาต์พุต เคยทำให้ไฟล์ชื่อ `--help` ค้างในรีโป (ลบแล้ว ยังไม่ได้แก้เครื่องมือ)
