# F6 ขยายทีละหน้า (เอกสาร B8 ข้อ 3 และ B6 ข้อ 6)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F5](F5-conveyor.md)

## เป้าหมาย
ตามเอกสาร: หน้าใหม่เกิดในโครงใหม่ทั้งหมด หน้าเก่าย้ายทีละกล่อง ไม่รื้อวันเดียว จบเมื่อทุกหน้าอยู่ใน `pages/` และชั้น `m/` เดิมหมด รายละเอียดลำดับขยายต่อเมื่อ F4 จบ เพราะต้องอิงสิ่งที่เรียนรู้จากกล่องนำร่อง

## ผลลัพธ์ที่ตรวจได้
1. ทุกหน้าตามตารางจับคู่ข้อ 3 ของแผนภาพรวมอยู่ในกล่องสามชั้นครบ
2. ชิ้นส่วนร่วม (`item-row, nav, sheet, dialog`) อยู่ใน `shared/`
3. `app/src/m` ว่าง ตรรกะของ 26 ไฟล์เดิมกระจายเข้า `pages/` `shared/` `data/` ตามหน้าที่
4. กล่องที่ผ่านเครื่องตรวจและแผ่นตรวจรับเท่านั้นที่ออกจากโซนกักรอตรวจ
5. ย้อนกลับได้รายกล่อง

## ข้อสังเกตจากของที่มีอยู่
- ลำดับย้ายเสนอ: หน้าเล็กก่อน (auth, detail, settings, focus) แล้ว ai, form, today และ calendar ท้ายสุดเพราะพึ่งตัวปฏิทินกับ store ร่วม
- `22-views__auth.ts` ใหญ่สุดของ m (22,333 ไบต์) ต้องแบ่งกล่องย่อยตามกฎกล่องล้นแบ่ง
- ลำดับจริงตัดสินหลังเห็นผลนำร่อง

## สิ่งที่ยังไม่ทราบ
- ลำดับย้ายที่ดีที่สุด (รอผล F4)
- เวลาที่ใช้ต่อกล่อง (ยังไม่เคยวัด)
