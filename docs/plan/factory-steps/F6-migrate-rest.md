# F6 ขยายทีละกล่อง (ช่วง: ไกล เป้าหมายกับเกณฑ์เท่านั้น)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ก่อนหน้า [F5](F5-conveyor.md)

## เป้าหมาย
ย้ายหน้าที่เหลือเข้ากล่องทีละกล่องตามหลักเอกสารโรงงาน B6: "หน้าใหม่เกิดในโครงใหม่ หน้าเก่าย้ายทีละกล่องเมื่อมีโอกาสแตะ ไม่รื้อวันเดียว"
ขยายรายละเอียดต่อเมื่อ F4 จบ เพราะลำดับและขนาดกล่องต้องอิงสิ่งที่เรียนรู้จากกล่องนำร่อง

## ผลลัพธ์ที่ตรวจได้
1. ทุกหน้าที่เป็น React (today, calendar, ai, settings, detail, form, auth ฯลฯ) อยู่ในกล่องครบสามชั้น
2. `app/src/m` ว่างหรือเหลือเฉพาะที่ระบุเหตุผล
3. กล่องที่ผ่านประตูเดิมและตัวตรวจแล้วเท่านั้นที่ออกจากโซนกักรอตรวจ
4. ย้อนกลับได้รายกล่อง (พังกล่องไหน ย้อนกล่องนั้น)

## สิ่งที่ทราบแล้วเกี่ยวกับกล่องที่เหลือ (จากสถานะ S4)
- หน้าที่พึ่ง store ร่วมและ FullCalendar (today, calendar) ซับซ้อนกว่านำร่อง ควรทำหลัง
- เปลือกแอป (nav, sheet, dialog, layers) ใช้ร่วมทุกหน้า ควรเป็น `shared/` ไม่ใช่กล่อง ต้องตัดสินใจตอน F6
- typing indicator ของหน้า AI ยังแทรกด้วย `insertAdjacentHTML` ลงใน container ที่ React ถืออยู่ (ปลอดภัยเพราะ remount ทุกครั้ง แต่ต้องย้ายเป็น React ตอนทำเปลือกแอป)
- `22-views__auth` ใหญ่สุดของชั้น m (22,333 ไบต์) แบ่งกล่องย่อยตามกฎ "กล่องล้นให้แบ่ง"

## สิ่งที่ยังไม่ทราบ
- ลำดับย้ายที่ดีที่สุด (ต้องรอผลวัดจาก F4)
- ว่า shared/ ควรมีกี่ชิ้นและรวมอะไรบ้าง
- เวลาที่ใช้ต่อกล่อง (ยังไม่เคยวัด)

## สถานะการเลื่อน
ขั้นนี้ตัดได้ก่อนเพื่อน (ดูแผนเสริมข้อ 9) การตัดเป็นของ Master เท่านั้น
