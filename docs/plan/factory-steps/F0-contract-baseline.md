# F0 ล็อกสัญญาและฐานวัด (ช่วง: ใกล้ รายละเอียดเต็ม)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ขั้นถัดไป [F1](F1-close-window-leaks.md)

## เป้าหมาย
ก่อนแตะโค้ดแม้บรรทัดเดียว: (1) ปิดข้อที่เปิดค้างกับ Master (2) ถ่ายเส้นฐานของโครงเดิมไว้ เพื่อให้ทุกขั้นถัดไปเทียบก่อน-หลังได้ด้วยตัวเลข ไม่ใช่ความรู้สึก
ขั้นนี้ไม่เปลี่ยนไฟล์ที่ผู้ใช้เห็น จึงไม่ต้อง bump service worker และไม่กระทบหมุดหมาย 2 พ.ย.

## ผลลัพธ์ที่ตรวจได้
1. Master ตอบ D1-D6 ในแผนเสริมข้อ 7 ครบ คำตอบถูกบันทึกลงแผนเป็นข้อตัดสินใจ (ไม่ใช่การเดา)
2. มีไฟล์เส้นฐานหนึ่งไฟล์ ถูก commit บน develop ประกอบด้วย: จำนวนไฟล์และขนาดต่อโซน, `Object.assign(window)` ต่อไฟล์, `window.` ต่อไฟล์แยกอ่าน/เขียน/บูต, ค่าสี/ระยะที่ฝังตรงใน CSS, ผลประตูเดิมทุกชุด (ผ่าน/ตก/จำนวนข้อ)
3. ผลประตูเดิมบน commit ปัจจุบันผ่านครบก่อนเริ่ม F1 (ถ้ามีตัวใดตกอยู่แล้ว ต้องบันทึกเป็นปัญหาเดิม ไม่ใช่ของแผนนี้)
4. Graphify ถูกรันรอบแรกกับ `app/src` ได้กราฟอ้างอิงสำหรับเทียบก่อน-หลัง

## เช็กลิสต์ตอบจุดเสี่ยง (จากตัวสอบ grillme)
- ค่าว่าง/ขอบเขต: เส้นฐานต้องระบุกรณีไฟล์ที่ไม่มีเลย (เช่น ไฟล์ไม่มี import) แทนที่จะข้าม
- ผลข้างเคียงต่อโมดูลอื่น: ขั้นนี้อ่านอย่างเดียว ไม่แก้
- ขีดจำกัดทรัพยากร: ประตูภาพรันนาน ห้ามรันเกิน 300 วินาทีในเชลล์ตรง ให้เปิดเบื้องหลังแล้วรอเป็นช่วง (บทเรียนจาก handoff S4)
- ย้อนกลับ: F0.5
