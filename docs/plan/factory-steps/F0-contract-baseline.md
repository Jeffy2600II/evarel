# F0 วัดเส้นฐาน

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md) | ถัดไป [F1](F1-warehouse-and-molds.md)

## เป้าหมาย
ก่อนย้ายอะไร ถ่ายภาพโครงเดิมและพฤติกรรมไว้เป็นหลักฐาน เพื่อพิสูจน์ได้ว่าหลังเปลี่ยนโครง ผู้ใช้เห็นเหมือนเดิมทุกพิกเซล ขั้นนี้อ่านอย่างเดียว ไม่แก้โค้ด

## ผลลัพธ์ที่ตรวจได้
1. ไฟล์เส้นฐานหนึ่งไฟล์ commit บน develop: จำนวนและขนาดไฟล์ต่อโซนเดิม, `window` ต่อไฟล์แยกอ่าน เขียน บูต, ค่าสีและระยะที่ฝังตรงใน CSS, ผลทดสอบเดิมทุกชุด (ผ่านหรือตก)
2. ภาพหน้าจอต้นฉบับของทุกหน้าทุกสถานะ เป็นภาพอ้างอิงเทียบหลังย้ายแต่ละกล่อง
3. ผลทดสอบเดิมบน commit ปัจจุบันบันทึกไว้ครบ ตัวที่ตกอยู่แล้วบันทึกเป็นของเดิม ไม่ใช่ของแผนนี้
4. Graphify รอบแรกกับ `app/src` ได้กราฟเส้นฐาน (เอกสารข้อ A: งานเว็บซับซ้อนต้องรัน Graphify ตั้งแต่ต้น) และรันซ้ำหลังจบแต่ละขั้น F1 ถึง F6 เพื่อเทียบโครงก่อนและหลัง
5. จุดถอยกลับ: commit อ้างอิง และสำเนา tar.gz ใน archive
