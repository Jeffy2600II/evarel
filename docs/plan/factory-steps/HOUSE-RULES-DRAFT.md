# ร่าง "กฎของบ้านนี้" และตารางถาม-ตอบกลาง (ร่างสำหรับ F2.1 ยังไม่ใช่ข้อบังคับ)

กลับไปที่ [แผนเสริม](../FACTORY-PLAN.md)

เอกสารโรงงานระบุให้มีไฟล์ "กฎของบ้านนี้" ไฟล์เดียว บอกเฉพาะที่ต่างจากมาตรฐานพร้อมเหตุผล อ่านจบหนึ่งหน้า และตารางถาม-ตอบกลาง ไฟล์นี้เป็นร่างตั้งต้นจากสิ่งที่วัดได้ ไม่ใช่ข้อสรุป

## ร่างกฎ (เฉพาะที่ต่างจากมาตรฐานวงการ)
| กฎ | เหตุผล |
|---|---|
| ภาพหน้าตาต้องตรงต้นฉบับ 0 พิกเซล ก่อนถือว่างานผ่าน | ผู้ใช้ต้องเห็นเหมือนเดิม และ Master ล็อกดีไซน์เดโมเป็น canonical |
| ไฟล์ที่ esbuild สร้าง ห้ามแก้หรือก๊อปทับ รัน build แล้ว `--check` | CI ตรวจไฟล์คอมไพล์ตรงซอร์ส พลาดแล้ว CI แดง |
| เปลี่ยนไฟล์ที่ผู้ใช้ได้รับ ต้อง bump รุ่น service worker | ไม่งั้นผู้ใช้ที่มีแคชไม่ได้ของใหม่ |
| ค่าที่ต้องการให้ Master รันเอง ต้อง push ขึ้น GitHub ก่อนบอกให้รัน | Master เปิดไฟล์ในเครื่องผมไม่ได้ |
| ชื่อไฟล์/โฟลเดอร์ไม่มีเลขเวอร์ชัน | กฎถาวรของ Master |
| main/production ไม่แตะ | กฎถาวรของ Master |
| เทสต์ที่คิดวันที่ในฝั่ง Node ต้องใช้ helper เวลา Bangkok | เคยตกคงที่ช่วง 17:00-24:00 UTC เพราะสองฝั่งเห็นคนละวัน |

## ตารางถาม-ตอบกลาง (ร่าง)
| ถ้าจะ… | ไปที่… |
|---|---|
| แก้ในหน้าเดียว | กล่องของหน้านั้น |
| แก้ปุ่มหรือสีทั้งเว็บ | แม่พิมพ์กลาง (tokens) |
| เพิ่มหน้าใหม่ | เบ้าจูน |
| เปลี่ยนรูปข้อมูลที่หน้ารับ | ถาดข้อมูล (contract) ของกล่องนั้น |
| ดูว่าแก้ชิ้นนี้กระทบหน้าไหน | ทะเบียนใครใช้ใคร |
| ตรวจหน้าเดียวโดยไม่สแกนทั้งโรงงาน | X-ray รายกล่อง |
